# Por qué Diátaxis

Esta docs sigue el [Diátaxis documentation framework](https://github.com/evildmp/diataxis-documentation-framework): cada página pertenece a un cuadrante según **qué necesita el lector**, no según el componente:

- **Tutoriales** (orientados a aprender): pasos que funcionan, sin atajos. Ej: despliegue local.
- **How-to** (orientados a la tarea): recetas puntuales con prerrequisitos. Ej: túnel, keys, flasheo.
- **Referencia** (orientada a información): contratos secos y exactos. Ej: tópicos MQTT, REST/OpenAPI.
- **Explicación** (orientada a entender): porqués y contexto. Ej: arquitectura.

Regla: si una página mezcla "cómo" con "por qué", se parte en dos. Los docs largos del repo (`docs/*.md`) quedan como fuente; aquí vive la versión navegable.
